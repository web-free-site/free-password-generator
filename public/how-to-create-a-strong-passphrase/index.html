How to create a strong passphrase

A passphrase is a password made of several words. Length makes it hard to guess, and words can be easier to type than a short string of symbols. Free Password Generator can create a Diceware-style passphrase on your device so the secret is not sent to a server.

Steps

  1. Use several random words, not a famous quote. A line from a book or a song is easier to guess than words drawn at random. Use the passphrase option in Free Password Generator rather than inventing a phrase from memory.
  2. Prefer more words over clever substitutions. Adding one more random word usually helps more than replacing letters with similar digits in a short phrase.
  3. Generate it in the browser and copy once. Create the passphrase, copy it into a password manager, and clear the field if you are on a shared computer.
  4. Use a unique passphrase for each important account. If one site is breached, the others should not open with the same phrase.

Managers still help

You do not have to memorize every passphrase. A password manager can store them and can generate random character passwords when a site rejects spaces or long phrases.

Site rules

Some forms cap length or forbid spaces. If a site will not accept a passphrase, generate a long random password instead and store that.
