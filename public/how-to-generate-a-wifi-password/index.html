How to generate a Wi-Fi password

A default router password printed on a sticker is often shared too widely or is too short. Generating a new, random password and saving it in a manager is a better habit. Free Password Generator can create a long password or a numeric PIN locally.

Steps

  1. Generate a long random password. Open Free Password Generator and create a high-length password. If the router rejects some symbols, turn those character types off and generate again.
  2. Copy it into a password manager first. Save the new password before you change the router, so you do not lock yourself out.
  3. Update the router or access point. Sign in to the router's administration page on a network you already control and set the new wireless password. Use a secure connection and follow the vendor's instructions.
  4. Update every device you own. Reconnect phones, computers, printers, and other devices. Share the password only with people who should use the network.

Guest networks

If your router supports a guest network, give visitors that password instead of the main one.

PINs are different from Wi-Fi keys

A short numeric PIN may be required for a device or a door code, but it is a weak choice for a wireless network. Use a long password for Wi-Fi whenever the router allows it.
